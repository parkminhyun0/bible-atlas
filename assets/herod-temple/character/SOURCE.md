# Temple visitor character sources

- Human anatomy base: Blender **Human Base Meshes v1.4.1**, Blender Studio and community contributors, CC0.
  - Official source: https://www.blender.org/download/demo-files/
  - The source `.blend` bundle is not redistributed in this repository.
- Historical clothing direction: project-supplied four-view reference image.
- Woven cloak surface: `visitor-cloak-weave-v1.png`, generated for this project from the supplied visual reference.

The committed GLBs are derivative runtime assets built by `tools/herod-temple/build-visitor-avatar.py`.
