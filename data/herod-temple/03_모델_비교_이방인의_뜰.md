# 03. 이방인의 뜰 — 두 모델 비교

2026-08-24. 새로 받은 `herod-temple-interior.glb` 와 현재 앱이 쓰는
`assets/herod-temple/ad30/lod1.glb` 를 `02_치수표.md` 의 고고학 치수와 대조했다.

측정 방법은 추정이 아니다. 두 GLB 를 직접 파싱해 노드 변환을 곱한 **월드 좌표
바운딩 박스**를 냈고, 병합 메시는 정점 히스토그램으로 층을 찾았다. 형태는
직교투영 래스터라이저로 그려 눈으로 확인했다(브라우저 탭이 백그라운드에서
얼어 Cesium 화면을 볼 수 없다).

## 3. 성역 안쪽 — 새 GLB 가 앞서는 부분

새 GLB 의 값어치는 이방인의 뜰이 아니라 **성역 내부**에 있다. 부재마다 이름이
붙어 있고 치수도 대체로 맞는다.

| 요소 | 기준 | 새 GLB |
|---|---|---|
| 성소 정면 | 100×100규빗 = 52.5×52.5 m | 52.50 × 52.50 ✓ |
| 성소 동서 총장 | 100규빗 = 52.5 m | 52.50 ✓ |
| 성소 후면 폭 | 70규빗 = 36.75 m (Middot 4:7) | 36.75 ✓ |
| 여인의 뜰 | 135×135규빗 = 70.9 m | 70.8 × 73 ✓ |
| 모서리 방 4개 | 40×40규빗 = 21 m | 21.0 ✓ (나실인·나무·나병환자·기름 이름까지) |
| 번제단 밑면 | 32×32규빗 = 16.8 m | 16.8 × 16.8 ✓ |
| 번제단 높이 | 10규빗 = 5.25 m | 5.2 ✓ |
| 니가노르 문 | War 5.201–205 | 문루·문짝·계단·기둥 갖춤 |
| 성소 내부 | 미돗 | 메노라·진설병상·분향단·휘장 있음 |
| **번제단 경사로** | Middot 3:3 「32×16, 남쪽」 = 남북 16.8 × 동서 8.4 | △ **남북 8.4 × 동서 16.2 — 90° 뒤집힘** |
| 헬 레벨 | 이방인의 뜰 +3.15 m | △ +1.33 m (여인의 뜰 바닥은 +3.93 m 로 서로 안 맞음) |

현재 lod1 도 성역 내부(`interior`·`sanct` 레이어)를 담고 있으나 부재가 병합돼
있어 개별 지명·해설을 붙이기 어렵다.

## 4. 판정

- **이방인의 뜰은 현재 lod1 이 확실히 낫다.** 주랑·왕의 주랑·문·계단이 모두
  요세푸스와 발굴 보고서 수치 그대로 들어가 있고, 대지도 실측 사다리꼴이다.
  새 GLB 의 이방인의 뜰은 얇은 단열 띠 하나로, 요세푸스가 명시한 이중 주랑과
  162주 왕의 주랑이 없다.
- **성역 안쪽은 새 GLB 가 낫다.** 부재가 분리돼 있어 해설·상호작용을 붙일 수
  있고, 소레그 경고비문·미크베·나실인 화덕 같은 세부까지 있다.
- 새 GLB 를 그대로 채택하면 이방인의 뜰이 크게 후퇴한다.

## 5. 구현 (2026-08-24)

판정대로 **바탕은 그대로, 성역 안쪽만 갈아 끼웠다.**

```
assets/herod-temple/ad30/
  lod1.glb          변경 없음 — 1인칭 순례 화면(temple-experience.html)이 쓴다.
                    그쪽은 doorCourt_*·veilOuter·sanct 노드 이름으로 상호작용을
                    거므로 성역을 도려내면 깨진다.
  mount-outer.glb   새로 굽는다. lod1 과 같되 성역 자리를 비웠다.
                    node tools/herod-temple/export-glb.cjs --carve-precinct \
                         --out assets/herod-temple/ad30/mount-outer.glb
  interior-v2.glb   새 GLB 의 성역 안쪽을 상류 프레임으로 옮겨 심은 것.
                    node tools/herod-temple/build-interior.mjs
```

Cesium 화면(`scripts/cesium/35-herod-temple-model.js`)은 이 둘을 **같은
modelMatrix** 로 올린다. 프레임이 같으므로 따로 정합할 것이 없다.

### 성역 자리 비우기
`export-glb.cjs --carve-precinct` 는 옛 500규빗 정방형 로컬 좌표로 성역
발자국(u 27~208 · v 41~129 m)을 잡고, 그 안에서 **포장면보다 위에 있는 것만**
걷어낸다(삼각형 19,554개). 포장면은 남긴다 — 상류 `LEV.chel = ESP` 라서 헬
바닥이 곧 이방인의 뜰 포장면이고, 새 모델은 헬 바닥을 갖고 오지 않는다.
